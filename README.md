## 🌟 为什么是「轻盈生活」

我们买的每样东西，都在用两种方式陪伴我们：**钱** 和 **时间**。

- 一支用了 300 天的键盘，日均成本可能只有几毛钱 —— 它值得被珍惜。
- 一台落灰的单反，买来从没拍过一张照片 —— 它的「每日陪伴总成本」里，藏着一个温柔的问号：**¥X ＋ ∞**。

绝大多数记账 App 只告诉你「花了多少」，却从不问「值不值」。**轻盈生活**反其道而行：它把成本摊薄到每一天、每一次使用，让你一眼看清「物尽其用」的快乐，也温柔地提醒你「是时候说再见了」。

> 我们相信：**物尽其用，轻盈地生活。**
>
> 在微信小程序里，这份心境会被写进底部的一行诗——它随主题而变：竹杖主题配苏轼「一蓑烟雨任平生」，鸢尾主题配「一花一世界，一叶一菩提」，星夜主题配「星垂平野阔，月涌大江流」。

## ✨ 核心特性

- **📊 双模式计费，让成本开口说话**
  - 按天数：自动算 `日均成本 = 价格 ÷ 陪伴天数`（陪伴从 **第 1 天** 算起，刚入手即 = 原价）
  - 按次数：手动 `+1 打卡`，算 `单次成本 = 价格 ÷ 打卡次数`；**0 次 = ∞**，看板会显示「¥X ＋ ∞」提醒你「买了却没用」
- **⚙️ 自定义状态 / 关系规则**：按你和物品的关系自定义状态（✨ 物尽其用、🌫️ 独自吃灰…），消极状态会拉低「轻盈度」并温柔提醒你断舍离
- **📈 轻盈度分析**：看板环形进度条，直观反映你的物品健康状态
- **🌫️ 断舍离提醒**：消极状态物品自动浮现温柔提醒，可「去告别」或「忽略」
- **✋ 长按卡片唤起菜单**：手机长按任意卡片，弹出「编辑 / 打卡一次 / 圆满告别 / 删除 / 恢复陪伴」快捷菜单
- **✏️ 点封面即编辑**：轻点物品左侧缩略图，直接改名称 / 价格 / 日期 / 分类 / 模式 / 备注 / 封面
- **🎨 emoji 封面**：照片之外可直接选 emoji 当封面；名字首字符是 emoji 且没传照片时自动用它当默认封面
- **💜 断·舍·离（圆满告别）**：优雅送别已离场的物品，需写告别评语；完成时**撒花 🎉 + 轻微震动**，去往「圆满告别」专区，不清算二手回血
- **⏳ 长久未见一目了然**：按次模式显示「上次使用 X 天前 / 已吃灰 X 天」，配合「长久未见」排序快速定位闲置好物
- **📄 分页浏览**：陪伴册每页最多 5 件，列表更轻
- **🔍 搜索**：同时匹配物品名称与备注 / 心情故事
- **🎨 三套主题，切换即换心境**：竹杖（薄荷绿）/ 鸢尾（梦幻紫）/ 星夜（深色），设置页一键切换，全局即时生效，底部诗句随主题而变
- **📖 内置使用指南**：随时查看完整图文教程（这是什么 / 两种计费怎么选 / 看懂看板 / 状态规则 / 断舍离 / 长按菜单 / 圆满告别 / 备份还原 / FAQ / 隐私），离线可用
- **🛡️ 自动备份，改动不丢**：每次增删改都自动留一份带时间戳的备份（最近 5 份），可随时回退；手动导出文件名也带时间戳
- **🏷️ 自定义分类**：分类不再写死，可新增 / 重命名 / 删除，删除时自动改派在用物品到其它分类
- **📤📥 备份 / 还原**：一键导出 / 导入 JSON，换设备也不丢（小程序内通过微信会话收发文件）

## 📱 三个版本

同一套理念，三种打开方式。数据模型完全一致，区别只在运行平台与存储方式。

### 1. Web App（单文件，完全离线）

零依赖、打开即用的网页版，数据存在浏览器 **LocalStorage**。

```bash
cd light-living
python -m http.server 8123
# 浏览器访问 http://127.0.0.1:8123/
```

### 2. Android APK（原生体验）

基于 Capacitor 打包，已发布正式版 `v1.2.0`。在 [GitHub Release](https://github.com/MistStride/LightLiving/releases) 下载 APK 安装即可。

### 3. 微信小程序 · 物尽其轻

- **名称**：物尽其轻
- **AppID**：`wx5389132842b00e33`
- **工程目录**：`miniprogram/`
- **技术栈**：微信原生小程序框架（WXML / WXSS / JS），无任何后端，数据存于微信本地 `Storage`（`wx.getStorageSync`，单 key ≤ 1MB / 总 ≤ 10MB），**不跨设备、不上传服务器**
- **运行方式**：用「微信开发者工具」导入 `miniprogram/` 目录，在 `project.config.json` 填入你的 AppID（或用自己的测试号），编译即可预览；上传 / 发布需在微信公众平台由管理员操作「提交审核 / 发布」
- **页面与结构**：
  - `pages/`：`index` 陪伴册（首页）、`add` 添加/编辑、`rules` 状态与关系规则、`categories` 分类管理、`settings` 我的、`about` 关于、`guide` 使用指南、`backup` 数据备份与恢复
  - `custom-tab-bar/` 自定义底部导航（陪伴册 🪶 / 我的 👤，背景随主题渐变，规避原生白底）
  - `components/nav-bar/` 自定义导航栏（透明 + 状态栏占位，消除夜间顶部白块）
  - `utils/store.js` 数据层（物品 / 分类 / 状态规则 / 成本计算 / 自动备份 / 导入导出）、`utils/theme.js` 三套主题令牌与诗句

> ⚠️ 小程序本地存储**不跨设备**：换手机后用「数据备份与恢复」导出 JSON 到微信会话，再在新设备导入即可迁移。

## 🚀 3 分钟上手

**Web / 手机浏览器**：按上方「Web App」步骤起一个本地服务，或把 `index.html` 传到任意静态托管直接打开。

**微信小程序**：用微信开发者工具导入 `miniprogram/` → 编译 → 首页点右下角 ＋ 记录第一件好物；首次进入若库为空，可点空态「载入示例好物」一键填充 5 件示例。

> 不知道从哪开始？先看 [使用指南](使用指南.md)，3 分钟学会添加第一件好物。

## 🗂 物品数据模型

| 字段 | 说明 |
|------|------|
| `id` | 时间戳字符串 |
| `name` | 物品名称 |
| `price` | 购买价格 |
| `purchaseDate` | 入手日期 `YYYY-MM-DD` |
| `category` | 自定义分类（默认：数码电子 / 服饰鞋包 / 居家生活 / 个人爱好 / 其他） |
| `mode` | `day`（按天）/ `count`（按次） |
| `useCount` | 打卡次数（count 模式生效） |
| `image` | 封面：照片（Base64，自动压缩至 ≤1000px）或 emoji 字符；留空时若名字首字符是 emoji 则自动用其当封面 |
| `note` | 随手备注 / 心情故事 |
| `status` | `active`（陪伴中）/ `archived`（已离场） |
| `farewellNote` | 告别评语（归档时必填） |
| `archiveReason` | 赠送 / 丢弃 / 转让 |
| `lastCheckin` | 最近一次打卡日期 |

Web / Android 数据存于浏览器 **LocalStorage**；微信小程序存于微信本地 **Storage**。两者均不上传任何服务器。

## 🧭 技术说明

**Web / Android**
- 纯原生 **HTML / CSS / JavaScript**，零依赖、秒开
- 数据存储：LocalStorage；通过 Capacitor 打包 Android
- 设计系统：淡紫 `#8B5CF6` + 淡蓝 `#93C5FD` 双色调，大圆角 20–24px，微阴影
- 目标设备：vivo S20（已做 Safe Area 适配）

**微信小程序**
- 微信原生小程序框架（WXML / WXSS / JS），`app.json` 全局 `navigationStyle: custom` + 自定义导航栏 / 底栏组件
- 数据存储：微信本地 `Storage`（`wx.getStorageSync` / `setStorageSync`）
- 三套主题通过 CSS 变量（`--primary` / `--surface` / `--hero-grad` 等）切换，页面根节点 `theme-{{theme}}` 驱动
- 导出/导入走 `wx.shareFileMessage`（发文件到聊天）与 `wx.chooseMessageFile`（从聊天选文件）

> 后续可演进方向：Web 转 React + Vite 工程、暗色模式、月度陪伴成本趋势图、物尽其用日历；小程序支持云开发实现跨设备同步等。

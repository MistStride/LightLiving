## 🌟 为什么是「轻盈生活」

我们买的每样东西，都在用两种方式陪伴我们：**钱** 和 **时间**。

- 一支用了 300 天的键盘，日均成本可能只有几毛钱 —— 它值得被珍惜。
- 一台落灰的单反，买来从没拍过一张照片 —— 它的「每日陪伴总成本」里，藏着一个温柔的问号：**¥X ＋ ∞**。

绝大多数记账 App 只告诉你「花了多少」，却从不问「值不值」。**轻盈生活**反其道而行：它把成本摊薄到每一天、每一次使用，让你一眼看清「物尽其用」的快乐，也温柔地提醒你「是时候说再见了」。

> 我们相信：**放手，轻盈地生活。**

## ✨ 核心特性

- **📊 双模式计费，让成本开口说话**
  - 按天数：自动算 `日均成本 = 价格 ÷ 陪伴天数`（陪伴从 **第 1 天** 算起，刚入手即 = 原价）
  - 按次数：手动 `+1 打卡`，算 `单次成本 = 价格 ÷ 打卡次数`；**0 次 = ∞**，看板会显示「¥X ＋ ∞」提醒你「买了却没用」
- **⚙️ 自定义状态 / 关系规则**：按你和物品的关系自定义状态（✨ 物尽其用、🌫️ 独自吃灰…），消极状态会拉低「轻盈度」并温柔提醒你断舍离
- **📈 轻盈度分析**：看板环形进度条，直观反映你的物品健康状态
- **🌫️ 断舍离提醒**：消极状态物品自动浮现温柔提醒，可「去告别」或「忽略」
- **✋ 长按卡片唤起菜单**：手机长按（或桌面右键）任意卡片，弹出「编辑 / 圆满告别 / 删除」快捷菜单，比点 ⋯ 更顺手
- **✏️ 点封面即编辑**：轻点物品左侧缩略图，直接改名称 / 价格 / 日期 / 分类 / 模式 / 备注 / 封面
- **🎨 emoji 封面**：照片之外可直接选 emoji 当封面；名字首字符是 emoji 且没传照片时自动用它当默认封面
- **💜 断·舍·离（圆满告别）**：优雅送别已离场的物品到「陪伴回忆录」，需写告别评语；完成时**撒花 🎉 + 播放庆祝音效**，不清算二手回血
- **⏳ 长久未见一目了然**：按次模式显示「上次使用 X 天前 / 已吃灰 X 天」，配合「长久未见」排序快速定位闲置好物
- **📄 分页浏览**：每页最多 5 件，列表更轻
- **🔍 搜索**：同时匹配物品名称与备注 / 心情故事
- **📖 内置使用指南**：点右上角 ⚙️ 设置，随时查看完整图文教程（这是什么 / 两种计费怎么选 / 看懂看板 / 状态规则 / 断舍离 / 长按菜单 / 圆满告别 / 备份还原 / FAQ / 隐私），离线可用
- **🛡️ 自动备份，改动不丢**：每次增删改都自动留一份带时间戳的备份（最近 5 份），可随时从「设置 → 恢复自动备份」回退；手动导出文件名也带时间戳
- **↩️ 系统返回手势关弹窗**：手机用屏幕边缘右滑 / 左滑或返回键，会先关掉当前弹窗而不是退出 App；在首页再按一次才退出
- **🏷️ 自定义分类**：分类不再写死，在「设置 → 物品分类管理」可新增 / 重命名 / 删除，删除时自动改派在用物品到其它分类
- **📤📥 备份 / 还原**：一键导出 / 导入 JSON，换设备也不丢
- **📱 移动端优先**：针对 vivo S20 做 Safe Area 适配（顶部挖孔 + 底部手势条），大圆角、微阴影、淡紫淡蓝双色调；也提供 Android APK（见 GitHub Release），装到手机即原生体验

## 🚀 3 分钟上手

这是一个**完全离线、单文件**的 Web App，零依赖、打开即用。

```bash
# 方式一：直接双击 index.html，用浏览器打开即可

# 方式二（推荐，避免个别浏览器对本地文件的存储限制）
cd light-living
python -m http.server 8123
# 浏览器访问 http://127.0.0.1:8123/
```

想用手机看？电脑手机连同一局域网，手机访问 `http://<电脑局域网IP>:8123/` 即可。

> 不知道从哪开始？先看 [使用指南](使用指南.md)，3 分钟学会添加第一件好物。

## 🗂 物品数据模型

| 字段 | 说明 |
|------|------|
| `id` | 时间戳字符串 |
| `name` | 物品名称 |
| `price` | 购买价格 |
| `purchaseDate` | 入手日期 `YYYY-MM-DD` |
| `category` | 自定义分类（默认：数码电子 / 服饰鞋包 / 居家生活 / 个人爱好 / 其他） |
| `mode` | `day`（按天）/ `count`（按次） |
| `useCount` | 打卡次数（count 模式生效） |
| `image` | 封面：照片（Base64，自动压缩至 ≤1000px）或 emoji 字符；留空时若名字首字符是 emoji 则自动用其当封面 |
| `note` | 随手备注 / 心情故事 |
| `status` | `active`（陪伴中）/ `archived`（已离场） |
| `farewellNote` | 告别评语（归档时必填） |
| `archiveReason` | 赠送 / 丢弃 / 转让 |
| `lastCheckin` | 最近一次打卡日期 |

所有数据保存在浏览器 **LocalStorage**，不上传任何服务器。

## 🧭 技术说明

- 纯原生 **HTML / CSS / JavaScript**，零依赖、秒开
- 数据存储：LocalStorage
- 设计系统：淡紫 `#8B5CF6` + 淡蓝 `#93C5FD` 双色调，大圆角 20–24px，微阴影
- 目标设备：vivo S20（已做 Safe Area 适配：`padding-top: max(env(safe-area-inset-top), 28px)`，底部预留系统手势条）

> 后续可演进方向：转 React + Vite 工程、用 Capacitor 打包成 Android APK、暗色模式、月度陪伴成本趋势图、物尽其用日历等。

# 轻盈生活 Light Living

> 轻盈的生活，认真对待我拥有的东西。

「轻盈生活」是一本**物品陪伴记录册** —— 它不是令人焦虑的强制断舍离工具，而是通过展示物品的「日均成本 / 单次成本」与「使用频次」，帮你珍惜陪伴自己的好物，也体面地放手不再需要的物品，从而获得轻盈、有质感的生活。

---

## ✨ 核心特性

- **双模式计费**
  - 按天数：自动计算 `日均成本 = 价格 / 陪伴天数`
  - 按次数：手动 `+1 打卡`，计算 `单次成本 = 价格 / 打卡次数`
- **自定义状态 / 关系规则** ⚙️
  - 按你和物品的关系自定义状态（如 ✨ 物尽其用、🌫️ 独自吃灰）
  - 标记为「消极」的状态会拉低「轻盈度」，温柔提醒你断舍离
  - 规则可新增 / 编辑 / 删除，条件支持多指标组合（满足全部 / 满足任一）
- **轻盈度分析**：看板环形进度条，直观反映你的物品健康状态
- **断舍离提醒 🌫️**：消极状态物品自动浮现温柔提醒，可「去告别」或「忽略」
- **圆满告别**：优雅归档已离场的物品到「陪伴回忆录」，需写告别评语，不清算二手回血
- **搜索 🔍**：同时匹配物品名称与备注 / 心情故事
- **备份 / 还原 📤📥**：一键导出 / 导入 JSON，数据换设备也不丢
- **移动端优先**：针对 vivo S20 做 Safe Area 适配（顶部挖孔 + 底部手势条），大圆角、微阴影、淡紫淡蓝双色调

## 🚀 运行方式

这是一个**完全离线、单文件**的 Web App，无需安装任何依赖。

- **方式一（最简单）**：用浏览器直接打开 `index.html`
- **方式二（推荐，避免个别浏览器对本地文件的存储限制）**：

  ```bash
  cd light-living
  python -m http.server 8123
  # 然后浏览器访问 http://127.0.0.1:8123/
  ```

- **手机预览**：电脑与手机连同一局域网，手机访问 `http://<你的电脑局域网IP>:8123/`

## 🗂 物品数据模型

每件物品（`Item`）字段：

| 字段 | 说明 |
|------|------|
| `id` | 时间戳字符串 |
| `name` | 物品名称 |
| `price` | 购买价格 |
| `purchaseDate` | 入手日期 `YYYY-MM-DD` |
| `category` | 数码电子 / 服饰鞋包 / 居家生活 / 个人爱好 / 其他 |
| `mode` | `day`（按天）/ `count`（按次） |
| `useCount` | 打卡次数（count 模式生效） |
| `image` | 物品照片（Base64，自动压缩至 ≤1000px） |
| `note` | 随手备注 / 心情故事 |
| `status` | `active`（陪伴中）/ `archived`（已离场） |
| `farewellNote` | 告别评语（归档时必填） |
| `archiveReason` | 赠送 / 丢弃 / 转让 |
| `lastCheckin` | 最近一次打卡日期 |

所有数据保存在浏览器 **LocalStorage**，不上传任何服务器。

## 🧭 技术说明

- 纯原生 **HTML / CSS / JavaScript**，零依赖、秒开
- 数据存储：LocalStorage
- 设计系统：淡紫 `#8B5CF6` + 淡蓝 `#93C5FD` 双色调，大圆角 20–24px，微阴影
- 目标设备：vivo S20（已做 Safe Area 适配：`padding-top: max(env(safe-area-inset-top), 28px)`，底部预留系统手势条）

> 后续可演进方向：转 React + Vite 工程、用 Capacitor 打包成 Android APK、暗色模式、月度陪伴成本趋势图、物尽其用日历等。

为什么是「轻盈生活」

我们买的每样东西，都在用两种方式陪伴我们：钱 和 时间。

  • 一支用了 300 天的键盘，日均成本可能只有几毛钱 —— 它值得被珍惜。
  • 一台落灰的单反，买来从没拍过一张照片 —— 它的「每日陪伴总成本」里，藏着一个温柔的问号：¥X ＋ ∞。

绝大多数记账 App 只告诉你「花了多少」，却从不问「值不值」。轻盈生活反其道而行：把成本摊薄到每一天、每一次使用，让你一眼看清「物尽其用」的快乐，也温柔地提醒你「是时候说再见了」。

🌿 我们相信：放手，轻盈地生活。

添加第一件好物

  • 点「＋ 添一件好物」，填写名称 / 价格 / 入手日期 / 分类。
  • 选择计费模式（见下），可选封面（照片或 emoji）。
  • 想改已添加的物品？轻点它的封面缩略图即可直接编辑。

💡 首次打开会有几件示例好物（📸⌨️🕯️🧣 等），帮你快速看懂界面。

两种计费模式，怎么选？

模式适合成本算法
按天 📅天天在用的：键盘、衣服、家具日均 = 价格 ÷ 陪伴天数（从第 1 天算起，刚买即 = 原价）
按次 ✋偶尔用的：相机、健身环、游戏单次 = 价格 ÷ 打卡次数；0 次 = ∞

💡 天天用的选「按天」，越用越便宜；偶尔用的选「按次」，每次用了点一下卡片上的 ＋1 打卡。

看懂首页看板

  • 每日陪伴总成本：所有「按天」物品的日均成本之和。若有「按次」物品 0 次没用过，这里显示「¥X ＋ ∞」——温柔提醒你为它每天在花「无限」的代价。
  • 在册好物：陪伴中的数量。
  • 轻盈度：环形进度条，积极状态占比越高越轻盈。
  • 已圆满告别：已送进回忆录的物品数。

💡「陪伴天数」从 1 天 起算，刚入手显示「陪伴 1 天」，日均 = 原价，符合直觉。

自定义状态与关系规则

点设置里的「状态与关系规则」，按你和物品的关系自定义状态（✨ 物尽其用 / 🌫️ 独自吃灰 / 💜 新伙伴）。可增删改，标记积极 / 消极 / 中性；还能加判定条件，比如给「按次」物品设「未使用天数 ≥ 30 天」就自动贴「🌫️ 独自吃灰」。消极状态会拉低轻盈度并触发断舍离提醒。

断舍离提醒

消极状态物品会在首页顶部浮现温柔提醒，列出「已吃灰 X 天」。可「去告别」或「忽略」。这步不强求，轻盈生活从不制造焦虑。

卡片的操作

  • 轻点封面 ✏️：编辑这件物品。
  • 长按卡片约 0.5 秒 ✋：弹出「编辑 / 圆满告别 / 删除」菜单。
  • ＋1 按钮（仅按次模式）：打卡一次。

圆满告别 · 断·舍·离

物品要离场时，别直接删——给它一场圆满告别：长按卡片选「圆满告别」，选原因并写一句告别评语（必填），点「圆满告别」后会 🎉 撒花 + 播放庆祝音效，并收进「陪伴回忆录」。想反悔？在回忆录里长按选「恢复陪伴」即可。直接「删除」会永久清除且不可恢复。

搜索、排序与分页

  • 搜索：同时匹配名称与备注 / 心情故事。
  • 排序：单位成本 高→低 / 低→高、陪伴时间、长久未见。
  • 分页：每页最多 5 件，底部「上一页 / 下一页」。

备份与还原（换手机不丢）

每次改动都会自动留一份带时间戳的备份（最近 5 份，存在本机），可从「设置 → 数据备份与恢复」随时回退。要换手机时，在该面板点「备份到文件」导出 light-living-备份-时间.json，到新设备「从文件还原」导入即可。

自定义分类

分类不再写死——点「设置 → 物品分类管理」可新增 / 重命名 / 删除分类；删除时会自动把在用的物品改派到其它分类，不会丢失。

封面与 emoji

可上传照片（自动压缩 ≤1000px），或直接选 emoji 当封面；名字首字符是 emoji 且没传照片时，会自动用它当封面。

常见问题

  • 为什么有 ＋ ∞？ 有「按次」物品 0 次没用过，它每天都在无限占用你的心思，去用用或告别吧。
  • 数据会丢吗？ 存在本机 LocalStorage，清 App 数据 / 卸载会丢，记得定期备份。
  • 能云端同步吗？ 当前纯本地单机版，可手动导出 JSON 传给另一台设备导入。
  • 长按没反应？ 在卡片空白处长按约 0.5 秒；桌面用右键。
  • 怎么退出弹窗？ 手机用系统「返回」手势（屏幕边缘右滑 / 左滑）或返回键，会先关掉当前弹窗而不是退出 App；在首页再按一次才会退出。
  • 庆祝音效没声？ 检查是否静音；音效由 Web Audio 实时合成，离线也能响。

隐私说明

所有数据仅存本机，不联网、不上传、不分析，无账号、无广告、无追踪。只有你主动「导出」时数据才会离开本机。
